# 水流が均等化されないときの確認ポイント

Flowing Fluids の均等化処理（`EnhancedFluidBFS.performEqualization`）が発火していても、以下の条件で水が動かない・止まって見える場合があります。

- **安定と判定されて探索がスキップされる**: `AdaptiveTickScheduler.shouldRunBFS` が平衡状態と判断すると、探索自体を開始しません【コード参照: `performEqualization` 内の安定判定】。
- **非置換ブロックによる流路の遮断**: 水には `ice` タグやスポンジが `nonDisplacer` として登録されており、これらのブロックは置き換えません【`FlowingFluids.init` での登録処理】。
- **地形と重み付けによる流れの偏り**: 探索は重力方向（下方向）に強く、上方向はモーメント予算が不足すると到達しません。段差がない場合や上り坂のみの場合、探索が早期に打ち切られることがあります【`performEqualization` でのモーメント計算と方向重み付け】。
- **探索深度・ノード上限に達した**: 動的深度やノード数上限により、遠い水路まで届く前に探索が終了します。特に水流距離設定を大きくしていても、地形が「海」判定だと浅い深度設定が選ばれます。

これらに該当しないかを確認したうえで、流路のブロックや地形、バイオーム設定を見直すと、均等化しない原因を絞り込めます。
