# Pass-Through Hydraulic Blocks Notes

- 症状: 鉄格子やフェンス系の隣で水が止まりやすく、下方向だけ通過しているつもりでも横方向では普通の仮想 waterlog と同じ見え方になっていた。
- 原因: 実流体の本判定は pass-through を許していても、横移動の実適用先は隣接 1 マス固定のままで、fast 判定や補助的な経路判定も pass-through を十分に追えていなかった。
- 対応: 横方向にも pass-through 連結先を解決する経路を追加し、鉄格子・フェンス・壁系を fast 判定でも通水可能として扱うよう揃えた。
- 追加調整: hydraulic blocks はライナーの補正を少し強め、ノズル向きにも流向補正を与えた。ツールチップ表示も実装して、何を強めるブロックか見返しやすくした。
- 今後の注意: pass-through を増やすときは、本判定だけでなく `fast` 判定、経路探索、実際の書き込み先解決が同じ規則になっているかをまとめて確認すること。
